# Инструкция по проверке оплаты аренды сервера

## 1. Перезапустите бота
```
Остановите текущего бота и запустите заново
```

## 2. Проверьте курс в telegram_stars_payments.py
Откройте файл и проверьте строку:
```python
STARS_TO_RUB_RATE = 1.5  # Ваш курс
```

## 3. Запустите тест
```bash
python tests\test_payment.py
```

Ожидаемый результат:
```
1 мес. = 250.0 ₽ → 166 ⭐️
2 мес. = 500.0 ₽ → 333 ⭐️
3 мес. = 750.0 ₽ → 500 ⭐️
6 мес. = 1500.0 ₽ → 1000 ⭐️
12 мес. = 3000.0 ₽ → 2000 ⭐️
```

## 4. Проверьте в боте
1. Нажмите `/start`
2. Выберите "🛒 Оплата товаров и услуг"
3. Выберите "🖥️ Аренда сервера"
4. Нажмите "⭐️ Оплатить Stars"

**Должна появиться клавиатура с актуальными ценами в звездах!**

## 5. Если клавиатура не показывает звезды
Проверьте, что импортируется правильная функция:

```python
# В server_rent_stars.py должно быть:
from handlers.payments.telegram_stars_payments import get_stars_amount
```

## 6. Если оплата не проходит
Проверьте логи бота - должна быть запись:
```
Создан инвойс для аренды сервера: X мес., Y звезд
```
