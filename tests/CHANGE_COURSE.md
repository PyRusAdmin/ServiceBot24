# 💱 Как изменить курс Telegram Stars

## 📍 Где менять курс

Откройте файл:
```
handlers/payments/payment_config.py
```

Найдите строку:
```python
STARS_TO_RUB_RATE = 1.5  # 1 звезда = 1.5 рубля
```

Измените значение:
```python
STARS_TO_RUB_RATE = 2.0  # 1 звезда = 2 рубля (новый курс)
```

## 🔄 Что обновится автоматически

После изменения курса и перезапуска бота, цены в звездах пересчитаются для:

### 1. Аренда сервера
- 1 месяц: 250 ₽ → 166 ⭐️ (при курсе 1.5)
- 2 месяца: 500 ₽ → 333 ⭐️
- 3 месяца: 750 ₽ → 500 ⭐️
- 6 месяцев: 1500 ₽ → 1000 ⭐️
- 12 месяцев: 3000 ₽ → 2000 ⭐️

### 2. MaxMaster
- 500 ₽ → 333 ⭐️

### 3. TelegramMaster-PRO
- 1600 ₽ → 1066 ⭐️

### 4. TelegramMaster_Commentator
- 1300 ₽ → 866 ⭐️

### 5. Пароли
- 300 ₽ → 200 ⭐️

## ✅ Проверка после изменения курса

1. **Запустите тест:**
   ```bash
   python tests\test_payment.py
   ```

2. **Проверьте в боте:**
   - `/start` → "🛒 Оплата товаров" → "⭐️ Оплатить Stars"
   - Цены в звездах должны пересчитаться

## 📊 Формула расчета

```python
звезды = рубли / STARS_TO_RUB_RATE
```

Пример при курсе 1.5:
- 250 ₽ / 1.5 = 166 ⭐️
- 500 ₽ / 1.5 = 333 ⭐️

Пример при курсе 2.0:
- 250 ₽ / 2.0 = 125 ⭐️
- 500 ₽ / 2.0 = 250 ⭐️
